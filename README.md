# وب‌سایت کاردرمنزل

این پروژه یک وب‌سایت ایستا و آماده انتشار در GitHub Pages است.

## انتشار در GitHub
1. فایل ZIP را از حالت فشرده خارج کنید.
2. تمام فایل‌ها و پوشه‌های داخل `kardarmanzel-github` را در مخزن GitHub بارگذاری کنید.
3. در مخزن به مسیر **Settings → Pages** بروید.
4. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.

صفحه اصلی پروژه `index.html` است.

## لینک‌های روبیکا
- کانال: https://rubika.ir/kardarmanzel_98
- مدیریت: https://rubika.ir/modir_ir98

لینک‌ها در دکمه‌های سربرگ، صفحه اصلی، صفحه همکاری، تماس و پابرگ فعال هستند.

## فایل‌ها
- `index.html`: صفحه اصلی
- `about.html`: درباره ما
- `cooperation.html`: فرصت همکاری
- `faq.html`: سؤالات متداول
- `contact.html`: تماس با ما
- `assets/style.css`: طراحی و واکنش‌گرایی
- `assets/hero-packing.jpg`: تصویر بخش اصلی
- `assets/rubika-mark.svg`: نشان گرافیکی روبیکا

یادآوری: بخش نماد اعتماد در حال حاضر فقط محل درج نشان رسمی است؛ تصویر یا کد تأییدنشده‌ای به‌عنوان نماد معتبر نمایش داده نشده است.
